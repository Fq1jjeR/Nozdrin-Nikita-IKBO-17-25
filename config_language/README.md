# Учебный конфигурационный язык (вариант №17)

Инструмент командной строки, преобразующий текст на учебном
конфигурационном языке в формат YAML. Разбор выполняется
специализированным инструментом синтаксического анализа
[Lark](https://github.com/lark-parser/lark), что обеспечивает
выявление синтаксических ошибок с детальными сообщениями о
позиции в исходном тексте.

Проект выполнен в рамках дисциплины «Конфигурационное
управление» (Ноздрин Никита, группа ИКБО-17-25).

## Общее описание

Инструмент читает исходный текст на учебном конфигурационном
языке из стандартного ввода и записывает результат в файл
формата YAML, путь к которому задаётся ключом командной строки
`-o` / `--output`. На этапе трансляции:

1. выполняется лексический и синтаксический разбор входного
   текста;
2. вычисляются объявленные константы и константные выражения;
3. строятся словари и числовые значения с учётом вложенности;
4. результат сериализуется в YAML.

Синтаксические ошибки (незакрытый словарь, недопустимое имя,
целое число вместо числа с плавающей точкой и т. п.)
выявляются с указанием строки и колонки.

### Синтаксис входного языка

**Многострочные комментарии** обрамляются `/* ... */` и могут
располагаться в любом месте программы:

```
/* Это многострочный
   комментарий */
```

**Числа** соответствуют регулярному выражению `[+-]?\d+\.\d+`,
то есть обязаны содержать десятичную точку и дробную часть:

```
1.0  -2.5  +3.14  0.0
```

**Словари** записываются в фигурных скобках; каждая запись
имеет вид `имя -> значение.`:

```
{
  host -> 0.0.
  port -> 5430.0.
}
```

**Имена** состоят из строчных латинских букв и знака
подчёркивания: `[_a-z]+`. Примеры: `host`, `max_size`, `a1`.

**Значения** могут быть числом, вложенным словарём, ссылкой на
константу или константным выражением.

**Объявление константы** на этапе трансляции:

```
base_port is 5430.0;
```

**Константное выражение** вычисляется на этапе трансляции и
записывается в форме `.( ... ).`:

```
area -> .(pi * radius * radius).
```

Доступны следующие операции и функции:

| Операция | Запись        | Описание                         |
| -------- | ------------- | -------------------------------- |
| `+`      | `a + b`       | Сложение                         |
| `-`      | `a - b`       | Вычитание                        |
| `*`      | `a * b`       | Умножение                        |
| `/`      | `a / b`       | Деление (ошибка при `b = 0`)     |
| `abs()`  | `abs(expr)`   | Модуль значения                  |
| `min()`  | `min(a, b, …)`| Минимум из произвольного числа   |

Приоритет операций стандартный: умножение и деление раньше
сложения и вычитания; круглые скобки изменяют порядок
вычисления.

## Описание функций и настроек

### `config_lang.Translator`

Класс, выполняющий разбор и трансляцию входного текста.

- `Translator()` — создаёт транслятор. Парсер Lark строится
  один раз и переиспользуется.
- `translate(source: str) -> str` — преобразует строку
  исходного текста в строку YAML. При синтаксической ошибке
  или ошибке вычисления выбрасывает
  `TranslationError`.

### `config_lang.TranslationError`

Исключение, описывающее ошибку трансляции. Содержит атрибуты
`message`, `line` и `column`, а также человеко-читаемое
строковое представление вида
`Строка 2, колонка 8: Необъявленная константа: unknown`.

### `config_lang.build_parser() -> Lark`

Возвращает настроенный экземпляр парсера Lark (алгоритм
Earley). Используется внутри `Translator`; может применяться
для самостоятельного разбора входного текста.

### `config_lang.GRAMMAR`

Строковая константа с грамматикой языка в формате EBNF для
Lark. Может использоваться для отладки и документирования.

### Настройки командной строки

| Ключ               | Обязателен | Описание                          |
| ------------------ | ---------- | --------------------------------- |
| `-o`, `--output`   | да         | Путь к файлу результата в YAML    |

Входной текст всегда читается из стандартного ввода.

## Команды сборки и запуска тестов

### Установка зависимостей

Создайте виртуальное окружение и установите зависимости.

**PowerShell:**

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Запуск транслятора

Запуск через лаунчер `run.py` (или обёртку `run.bat`, которая его
вызывает).

**PowerShell:**

PowerShell не поддерживает оператор перенаправления ввода `<`.
Чтобы передать файл на stdin, используйте `Get-Content ... |`.

```powershell
# Напрямую через run.py
'{ a -> 1.0. }' | python run.py -o out.yaml

# Через скрипт run.bat
'{ a -> 1.0. }' | .\run.bat out.yaml

# Из файла (ВАЖНО: Get-Content, а не оператор <)
Get-Content examples\db.cl | python run.py -o out.yaml
```

### Запуск тестов

```
python -m pytest -q
```

### Генерация примеров

**PowerShell**

```
# PowerShell (не использует оператор < — только Get-Content ... |)
Get-Content examples\db.cl | python run.py -o examples\db.yaml
Get-Content examples\game.cl | python run.py -o examples\game.yaml
```

```

├── src/
│   └── config_lang/
│       ├── __init__.py     — публичный API пакета
│       ├── __main__.py     — точка входа CLI
│       ├── grammar.py      — грамматика языка (EBNF для Lark)
│       ├── parser.py       — построение парсера Lark
│       └── translator.py   — транслятор в YAML и AST-преобразование
├── tests/
│   ├── conftest.py
│   ├── test_translator.py — тесты всех конструкций языка

├── examples/
│   ├── db.cl              — пример конфигурации базы данных

├── .gitignore
├── pyproject.toml
├── requirements.txt
├── run.py                 — лаунчер CLI (главный, вызывается напрямую)

└── README.md
```

## Технологии

- **Python 3.10+** — язык реализации.
- **Lark** — специализированный инструмент синтаксического
  разбора (алгоритм Earley).
- **PyYAML** — сериализация результата в YAML.
- **pytest** — модульное тестирование.
