## Навигация по проектам

### 📁 Практика №1: Эмулятор оболочки ОС

Вариант №17. Разработка эмулятора для языка оболочки ОС
с графическим интерфейсом (GUI) на базе Python.

- Формирование заголовка окна на основе реальных данных ОС
  (`Эмулятор - [username@hostname]`).
- Эмуляция виртуальной файловой системы (VFS) и базовых команд
  консоли.
- Подробное описание и инструкции:
  [PR_1_README.md](PR_1_shell_emulator/PR_1_README.md)

### 📁 Практика №2: Визуализатор графа зависимостей

Вариант №17. Инструмент командной строки для анализа
и визуализации графа зависимостей пакетов Cargo (Rust).

- Обход дерева зависимостей (BFS без рекурсии), учёт максимальной
  глубины анализа и циклических зависимостей.
- Вывод обратных зависимостей и визуализация графа через Graphviz
  в формате PNG.
- Подробное описание и инструкции:
  [PR_2_README.md](PR_2_dependency_graph/PR_2_README.md)

### 📁 Домашняя работа: Транслятор конфигурационного языка

Вариант №17. Разработка транслятора пользовательского учебного
конфигурационного языка в формат YAML.

- Разработан собственный синтаксический анализатор на базе Lark.
- Объявление констант и вычисление константных выражений
  (`+`, `-`, `*`, `/`, `min()`, `abs()`).
- Подробное описание, синтаксис и инструкции:
  [Home_Work_README.md](Home_Work_config_language/Home_Work_README.md)
