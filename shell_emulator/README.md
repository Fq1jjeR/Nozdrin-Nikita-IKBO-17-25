## 1. Общее описание
Проект представляет собой эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI). Заголовок окна формируется динамически на основе реальных данных операционной системы (в формате Эмулятор-[username@hostname]). Эмулятор работает с виртуальной файловой системой (VFS), источником которой является директория на диске пользователя. Все операции производятся исключительно в оперативной памяти.
## 2. Описание всех функций и настроек
Эмулятор поддерживает запуск со следующими параметрами командной строки:
* `--vfs` — путь к директории на диске пользователя, которая используется в качестве источника виртуальной файловой системы (VFS).
* `--script` — путь к стартовому скрипту, содержащему набор команд. Скрипт поддерживает комментарии, а при его выполнении на экране отображаются как ввод, так и вывод, имитируя диалог с пользователем.

**Поддерживаемые команды:**
* `ls` — вывод содержимого директории (заглушка).
* `cd` — смена директории (заглушка).
* `exit` — завершение работы эмулятора.
